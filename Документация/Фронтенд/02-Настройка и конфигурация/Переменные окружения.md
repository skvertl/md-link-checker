## Краткое содержание

Этот документ предоставляет справочник по переменным окружения в проекте Python-TypeScript Wiki Frontend. Описаны переменные из `.env.example`, `src/env.d.ts` и `process.env` (Playwright/E2E), а также их фактическое использование в коде.

---

## О файле src/env.d.ts

**src/env.d.ts** — это TypeScript declaration file, который объявляет типы для переменных окружения. Он обеспечивает:
- Автокомплит переменных в IDE (IntelliSense)
- Проверку типов на этапе компиляции
- Защиту от опечаток в названиях переменных

**Важно:** Наличие переменной в `src/env.d.ts` НЕ означает, что она обязательна или используется. Это лишь TypeScript-контракт для тех переменных, которые *могут* использоваться в коде.

**Несоответствия между `.env.example` и `src/env.d.ts`:**  
В проекте существуют переменные, объявленные только в одном из файлов. Для каждой переменной в документации указано, где она присутствует:
- **E** — `.env.example` (что нужно настроить)
- **D** — `src/env.d.ts` (что TypeScript знает)
- **K** — используется в коде (что реально работает)

## Используемые переменные

Только эти 4 переменные используются в runtime-коде фронтенда (`src/**`).  
Переменные `PORT`, `E2E_BASE_URL` и `CI` используются в E2E/Playwright-конфигурации.

### VITE_APP_ENV

**Местоположение:** `.env.example` ✅ | `src/env.d.ts` ✅  
**Используется в коде:** ✅ Да  
**Тип:** `enum('local' | 'development' | 'production')`  
**По умолчанию:** `'local'` (в коде), `development` (в .env.example)

Окружение выполнения. Определяет режим работы приложения.

**Важно:** Если переменная не установлена, код использует значение `local`. В `.env.example` задано значение `development`.

```bash
# Mock режим (основные списки/детали через mock)
VITE_APP_ENV=local

# Real API режим
VITE_APP_ENV=development

# Production режим
VITE_APP_ENV=production
```

**Использование в коде:**
```typescript
// src/shared/lib/environment.ts
const APP_ENV = import.meta.env.VITE_APP_ENV || 'local';
export const isLocalRun = () => APP_ENV === 'local';
```

**Влияние:**
- Переключение между mock и real API через `isLocalRun()`

---

### VITE_API_BASE_URL

**Местоположение:** `.env.example` ✅ | `src/env.d.ts` ✅  
**Используется в коде:** ✅ Да  
**Тип:** `string`  
**Пример:** `http://training.wiki:8000`

Базовый URL backend API. Запросы через `fetchWithToken` отправляются на этот URL.

```bash
VITE_API_BASE_URL=http://training.wiki:8000
```

**Использование в коде:**
```typescript
// src/shared/lib/environment.ts
export const BASE_URL = import.meta.env.VITE_API_BASE_URL;

// src/shared/lib/fetch-mutator.ts
const urlObj = new URL(url, BASE_URL);
```

---

### VITE_SSO_APP_ID

**Местоположение:** `.env.example` ✅ | `src/env.d.ts` ❌  
**Используется в коде:** ✅ Да  
**Тип:** `string`  
**Пример:** `your-app-id`

ID приложения в SSO сервисе для авторизации через OAuth.

```bash
VITE_SSO_APP_ID=your-sso-app-id
```

**Использование в коде:**
```typescript
// src/shared/lib/environment.ts
export const APP_ID = import.meta.env.VITE_SSO_APP_ID;

// src/pages/auth/ui/AuthPage.tsx
return `https://sso.oauth.name/access/?grant=${APP_ID}`;
```

**Примечание:** Переменная отсутствует в `src/env.d.ts`, но используется в runtime-коде (`src/shared/lib/environment.ts`).

---

### VITE_BYPASS_AUTH

**Местоположение:** `.env.example` ❌ | `src/env.d.ts` ✅  
**Используется в коде:** ✅ Да  
**Тип:** `string` (`'true' | 'false'`) в runtime

Обход авторизации для разработки.

```bash
# Отключить проверку авторизации в guard
VITE_BYPASS_AUTH=true

# Любое другое значение (или отсутствие переменной) оставляет проверку включенной
VITE_BYPASS_AUTH=false
```

**Использование в коде:**
```typescript
// src/shared/lib/environment.ts
export const FEATURE_AUTH_BYPASS = import.meta.env.VITE_BYPASS_AUTH === 'true';

// src/shared/lib/auth-utils.ts
export function requireAuth(currentPath: string): void {
  if (FEATURE_AUTH_BYPASS) {
    return; // Пропускаем проверку авторизации
  }
  // ... остальная логика
}
```

**⚠️ Важно:**
- Отсутствует в `.env.example`, но используется в коде
- Если переменная не указана, авторизация **включена** (значение `false`)
- Для отключения авторизации укажите `VITE_BYPASS_AUTH=true`
- В `src/env.d.ts` объявлена как `boolean`, но в runtime сравнивается со строкой `'true'`

## Примеры конфигураций

### Минимальные конфигурации

Эти конфигурации содержат только переменные, которые реально используются в коде.

#### Local окружение (`VITE_APP_ENV=local`)

```bash
VITE_APP_ENV=local
# Опционально:
# VITE_BYPASS_AUTH=true
```

**Что происходит:**
- В `useSpaces` и `useSpace` включается чтение mock-данных (`spaceMocks`)
- `VITE_BYPASS_AUTH=true` отключает guard в `requireAuth`
- `createSpace` по-прежнему вызывает backend API (`POST /api/v1/spaces`)

---

#### Non-local окружение (`VITE_APP_ENV=development` или `production`)

```bash
VITE_APP_ENV=development  # или production
VITE_API_BASE_URL=http://training.wiki:8000
VITE_SSO_APP_ID=your-app-id
```

**Что происходит:**
- `isLocalRun()` возвращает `false`
- `useSpaces` и `useSpace` работают через `fetchWithToken` и `VITE_API_BASE_URL`
- URL авторизации формируется из `VITE_SSO_APP_ID`
- `VITE_BYPASS_AUTH=true` всё ещё отключает guard (значение окружения в коде не проверяется)

---

### Полная конфигурация (как в .env.example)

Эта конфигурация соответствует `.env.example`. Переменные, которые **используются в коде**, помечены ✅.

```bash
# Приложение
VITE_APP_NAME=wiki-frontend              # ❌ не используется
VITE_APP_ENV=development                  # ✅ используется
VITE_APP_DEBUG=true                       # ❌ не используется

# API
VITE_API_BASE_URL=http://training.wiki:8000  # ✅ используется
VITE_API_TIMEOUT=30000                     # ❌ не используется

# Docker (только для docker-compose)
DOCKER_FRONTEND_PORT=3000                 # ❌ не используется (legacy)
DOCKER_FRONTEND_HOST=0.0.0.0              # ❌ не используется (legacy)

# TanStack Query
VITE_QUERY_STALE_TIME=300000              # ❌ не используется
VITE_QUERY_CACHE_TIME=600000              # ❌ не используется

# Auth
VITE_AUTH_TOKEN_MAX_AGE_MS=3600000        # ❌ не используется

# SSO
VITE_SSO_APP_ID=                          # ✅ используется
VITE_APP_DOMAIN=https://training.wiki     # ❌ не используется

# Безопасность
VITE_ALLOWED_ORIGINS=http://localhost:3000,http://localhost:8000  # ❌ не используется

# Тесты
TEST_SSO_APP_ID=                           # ✅ используется в E2E тестах
```

**Примечание:** Для runtime-кода фронтенда (`src/**`) используются `VITE_APP_ENV`, `VITE_API_BASE_URL`, `VITE_SSO_APP_ID`, `VITE_BYPASS_AUTH`; `TEST_SSO_APP_ID` используется в E2E.

## Доступ к переменным в коде

### Прямой доступ через import.meta.env

```typescript
// Доступ к переменной окружения
const apiUrl = import.meta.env.VITE_API_BASE_URL;

```

### Доступ через утилиты в shared/lib

```typescript
// src/shared/lib/environment.ts
export const APP_ID = import.meta.env.VITE_SSO_APP_ID;
export const BASE_URL = import.meta.env.VITE_API_BASE_URL;
const APP_ENV = import.meta.env.VITE_APP_ENV || 'local';

export const isLocalRun = () => APP_ENV === 'local';
```
