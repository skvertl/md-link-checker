# `md-link-checker` 🔗

> **Markdown Link & Dead Code Checker** — асинхронный CLI-инструмент на Python 3.11 для проверки валидности локальных ссылок на файлы и внешних HTTP/HTTPS URL-адресов в Markdown-документах.

---

## 🌟 Основные возможности

- **🔍 Автоматический рекурсивный поиск**: Сканирует всю структуру директорий для поиска `.md` файлов.
- **🛡️ Исключение служебных папок**: Игнорирует служебные директории (`node_modules`, `.git`, `.venv`, `venv`, `dist`, `build`, `__pycache__`, `.idea`, `.vscode`).
- **💡 Умное извлечение ссылок**:
  - Распознает стандартные ссылки `[текст](url)`, изображения `![alt](url)` и автоссылки `<http...>`, `<file...>`.
  - **Игнорирует блоки кода**: Код внутри огражденных блоков (`` ```...``` ``) и инлайн-вставок (`` `...` ``) вырезается перед парсингом, предотвращая ложные срабатывания на примеры кода.
  - Игнорирует внутристраничные якоря (`#section`) и непроверяемые протоколы (`mailto:`, `tel:`, `javascript:`).
- **📂 Контекстный резолвинг локальных путей**:
  - Относительные пути (например, `./image.png`, `../docs/guide.md`) проверяются **строго относительно папки текущего `.md` файла**, а не корня запуска CLI.
  - Декодирует URL-кодировку (например, `%20` -> пробел) и схемы `file://`.
  - Корректно отсекает фрагментные якоря (`doc.md#installation`).
- **⚡ Асинхронная проверка сети (HTTP/HTTPS)**:
  - Ограничение параллельности через `asyncio.Semaphore(15)` и таймаут `5.0` секунд.
  - **Двухэтапная стратегия HEAD → GET**: Сначала отправляется быстрый `HEAD`-запрос. Если сервер возвращает код ответа `≥ 400` (например, Figma или GitHub), запрашивается потоковый `GET`-запрос (считывающий только заголовки).
  - **Устойчивость к лимитам**: Автоматические повторные попытки (retry + backoff) при статусах `429 Too Many Requests` и временных тайм-аутах.
- **🎨 Премиальный UI терминала (`rich`)**:
  - Живой индикатор прогресса (progress bar / spinner).
  - Наглядная итоговая таблица результатов с цветовой индикацией (`VALID` / `BROKEN`).
  - Сводная панель статистики.
- **🤖 CI/CD Совместимость**: Возвращает код завершения `0` при успешной проверке всех ссылок и `1` при наличии хотя бы одной битой ссылки.

## 🚀 Быстрый запуск

### 1. Требования
- Python **3.11.8+**

### 2. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 3. Использование

Запустите скрипт через Python:
```bash
python checker.py
```

При запуске появится интерактивный запрос:
```text
Enter directory path to check (press Enter to scan current directory):
```
- Нажмите **Enter**, чтобы отсканировать текущую директорию.
- Или введите относительный / абсолютный путь к целевой папке.
