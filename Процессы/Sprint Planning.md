# Sprint Planning

## 🎯 Цель
Определить цель спринта, выбрать задачи и составить реалистичный план выполнения.

## 👥 Участники
- Product Owner (ведущий)
- Scrum Master (фасилитатор)
- Вся команда

## 📥 Входящие артефакты
- Обновлённый backlog
- Результаты прошлого спринта
- Архитектурные решения / ADR
- UX макеты (если есть)

## 📤 Выходящие артефакты
- Sprint Goal
- Sprint Backlog
- Оценки задач
- Приоритеты и зависимости
- Назначения по задачам

## ⏱ Регламент
- 30 минут

## 🗂 Этапы
1. PO напоминает контекст и цель продукта  
2. Обзор backlog  
3. Обсуждение задач  
4. Оценка сложности  
5. Формирование Sprint Goal  
6. Составление Sprint Backlog  
7. Фиксация договорённостей в трекере

## ✔️ Чеклист
- [ ] Цель спринта определена  
- [ ] Задачи готовы к работе  
- [ ] Есть оценки  
- [ ] Понятны зависимости  
- [ ] Sprint Backlog сформирован
