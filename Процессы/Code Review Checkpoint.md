# Code Review Checkpoint

## 🎯 Цель
Проверить качество открытых PR, минимизировать риски, синхронизировать стандарты разработки.

## 👥 Участники
- Tech Lead (ведущий)
- Все разработчики

## 📥 Входящие артефакты
- Список открытых PR
- Code style guide
- Архитектурные договорённости

## 📤 Выходящие артефакты
- Приоритизированный список PR
- Решения по спорным вопросам
- Обновлённый план review

## ⏱ Регламент
- 20–40 минут
- 1 раз за спринт

## 🗂 Этапы
1. Разбор критичных PR  
2. Обсуждение крупных изменений  
3. Решение технических вопросов  
4. Согласование сроков review  

## ✔️ Чеклист
- [ ] Техдолг выявлен  
- [ ] Спорные PR разобраны  
- [ ] Приоритеты review определены  
- [ ] Договорённости зафиксированы
