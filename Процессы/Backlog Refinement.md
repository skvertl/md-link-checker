# Backlog Refinement

## 🎯 Цель
Подготовить задачи к будущим спринтам, уменьшить неопределённость и согласовать критерии готовности.

## 👥 Участники
- Product Owner (ведущий)
- Team Lead
- Команда

## ⏱ Регламент
- 30–45 минут
- 1 раз за спринт

## 📥 Входящие артефакты
- Backlog
- UX прототипы (если есть)
- Архитектурные ограничения

## 📤 Выходящие артефакты
- Уточнённые задачи
- Acceptance Criteria
- Оценки / t-shirt sizes
- Обновлённый backlog

## 🗂 Этапы
1. PO объясняет задачи  
2. Команда задаёт вопросы  
3. Уточняются требования  
4. Добавляются AC  
5. Технические комментарии  
6. (Если возможно) предварительная оценка  

## ✔️ Чеклист
- [ ] Описание задачи понятно  
- [ ] Есть AC  
- [ ] Вопросы закрыты  
- [ ] Зависимости известны  
- [ ] Задача готова к оценке
