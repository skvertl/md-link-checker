# Mid-Sprint Sync / Check-in

## 🎯 Цель
Синхронизировать команду, снять блокеры, проверить движение к Sprint Goal.

## 👥 Участники
- Scrum Master (ведущий)
- Вся команда

## ⏱ Регламент
- 15–30 минут
- 1 раз в неделю (заменяет дневные стендапы)

## 🗂 Формат
Каждый отвечает:
1. Что сделал?
2. Что планирует сделать?
3. Какие есть блокеры?

## 📥 Входящие артефакты
- Состояние задач в трекере
- Текущий прогресс по Sprint Goal

## 📤 Выходящие артефакты
- Список блокеров
- Решения по перераспределению задач

## ✔️ Чеклист
- [ ] Статусы задач обновлены  
- [ ] Блокеры зафиксированы  
- [ ] Понятен прогресс  
- [ ] Задачи перераспределены (если нужно)
